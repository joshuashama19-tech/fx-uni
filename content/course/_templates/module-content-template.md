# Module Content Template

This is the reusable structure every module's `01-content.md` should
follow, established by Module 1. Copy this skeleton when writing Modules
2–10 so the course stays consistent, then replace each section with real
content. Delete these instructional notes (in *italics*) as you go — they
are not part of the finished course.

Each module also gets its own `02-exercises.md`, `03-quiz.md`,
`04-answer-key.md`, and `05-checklist.md`, following Module 1's files as
the pattern.

---

# Module N — [Module Title]

*"[A short subtitle that captures the module's promise, in one line.]"*

## Module Introduction

*Two to four short paragraphs. What this module covers, why it matters,
and how it connects to the module before and after it. Written directly
to the student ("you").*

## Learning Objectives

*A short bullet list — 6 to 10 items — phrased as "By the end of this
module, you will be able to..." Each objective should be concrete and
checkable, not vague ("understand risk" is vague; "calculate position
size from a fixed risk amount and stop-loss distance" is checkable).*

### Lesson 1 — [Lesson Title]

*Repeat this pattern for every lesson in the module (Module 1 has 13;
other modules may have fewer, depending on topic count). Every lesson
should, where the concept allows it, move through this sequence:*

1. **Plain-language explanation first.** Introduce the idea with an
   everyday comparison before naming it formally.
2. **Formal definition / terminology.** Name it properly once the student
   already has the intuition.
3. **Why it matters.** Connect it to a decision the student will actually
   make while trading.
4. **How it works, with a realistic worked example.** Use plausible
   prices and numbers (no "$1,000/day" style claims) and walk through
   them step by step.
5. **What it looks like in an actual trade / on an actual chart.**
6. **A common beginner mistake related to this concept**, and why it
   happens.

*(Not every lesson needs every element in that exact order, but every
lesson should answer: what is it, why does it matter, how does it work,
what does it look like in practice, and what mistake do beginners make
with it.)*

## Common Beginner Mistakes (module-wide recap)

*A consolidated list of 5–8 mistakes covered across the module's lessons,
gathered in one place as a quick-reference recap.*

## Practical Examples

*One or two longer, multi-step worked scenarios that combine several
concepts from the module, walked through in full.*

## Key Takeaways

*A short bullet recap — one line per major concept covered.*

## Before You Move On

*A short checklist ("I can explain...", "I can calculate...") the student
self-checks before starting the next module. The full, formal version of
this lives in the module's separate `05-checklist.md` file.*

## Formatting conventions used across all modules

- **Headings**: `#` for the module title (one per file), `##` for each
  major section (Module Introduction, Learning Objectives, Common
  Beginner Mistakes, Practical Examples, Key Takeaways, Before You Move
  On), and `###` for each individual lesson. This is the exact hierarchy
  Module 1 uses — keep it consistent so the content can later be
  assembled into a single PDF without heading-level clashes.
- **Worked examples**: presented as a labeled block (`**Example:**`)
  followed by a step-by-step walkthrough, or as a table when comparing
  several values (e.g. different lot sizes).
- **Definitions**: short and stated in plain English before any formula.
- **Warnings / risk notes**: called out explicitly, not buried in a
  paragraph — use a `> **Note:**` or `> **Risk note:**` blockquote.
- **No invented statistics, credentials, or claims.** The only confirmed
  external fact about FX University that may be referenced anywhere in
  course content is that it has trained 5,000+ students. No performance
  claims, win rates, or income figures are ever attached to that number.
- **Tone**: confident, direct, and professional — never hypey, never
  fearful. Assume an intelligent adult who simply hasn't been taught this
  material yet.
