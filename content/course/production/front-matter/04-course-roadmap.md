# Course Roadmap

The ten modules build on each other in a fixed order, moving from market
basics through analysis, risk, psychology, planning, testing, and
practical application — then into an ongoing development cycle that
continues after the course itself ends.

```

  ↓

Module 2 — Reading & Understanding Charts
  ↓
TECHNICAL ANALYSIS

  ↓

Module 5 — Fundamental Analysis
  ↓
RISK CONTROL

  ↓

  ↓

  ↓
PRACTICAL DEVELOPMENT
Module 10 — Practical Forex Development
  ↓
CONTINUED DEVELOPMENT
90-Day Development Roadmap
```

## Reading this roadmap

Each stage's label describes the *kind* of skill that module adds, not a
level of difficulty — Modules 1–5 build the ability to read and analyze
a market; Modules 6–7 build the discipline layer (risk control and
psychology) that makes that analysis usable; Module 8 turns all of it
into one written, personal set of rules; Module 9 tests those rules
against evidence and builds the habit of recording results; Module 10
applies the complete framework responsibly in the real world. The
90-Day Development Roadmap at the bottom isn't an eleventh module — it's
the practical continuation of Module 10's own final lesson, since the
Learn → Understand → Practice → Backtest → Journal → Improve cycle this
course teaches doesn't stop when the last module does.

This roadmap describes a learning sequence, not a guaranteed path to
profitable trading — see each module's own material for the specific,
honest limits of what it teaches.
